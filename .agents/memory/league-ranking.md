---
name: League ranking
description: The user's ranking and end-of-season contribution rules.
---

Leaderboard rankings use record first, then lower contribution when records
match. For example, a player contributing $60 ranks above a player contributing
$75 with the same record.

**Why:** The user stated that the ultimate winner is the person with the least
contribution at the end of the season.

**How to apply:** Preserve the contribution tie-break when updating standings.
Do not interpret an alphabetical display order for completely tied players as
a rule for deciding the league winner.
